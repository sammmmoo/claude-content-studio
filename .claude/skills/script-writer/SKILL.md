# script-writer

**Outcome:** a script the creator copies straight into a teleprompter and reads naturally, and a viewer with the problem watches to the end.

Start from an outlier (topic-finder). Copy its beats one for one; write every sentence fresh. Get the hooks from hook-writer.

## The file has two parts

```
<n>. <WHERE YOU FILM>: <VIDEO NAME>

=== READ THIS (copy into the teleprompter) ===
[Name, hook A]  ...
[Name, hook B]  ...
[Name, super hook]  ...
[Name, stack A]  ...
[Name, lock-in A]  ...
[Name, body one]  ...
[Name, body two]  ...
[Name, payoff]  ...
[Name, CTA A]  ...

=== FOR THE EDIT (not read aloud) ===
Text hooks, frame 0, what shows on screen for each line, the re-hook map, the caption, the source outlier.
```

READ THIS holds only the slate in [brackets] and the words to say. No text hooks, no stage directions, no pause marks, no "say it as written". Bullets (•) mark lines the creator can say their own way.

## How the body reads

- **Long, then short.** A longer line that tells the story, then a 2-6 word punch. "Ten unpaid hours a week, over fifty weeks, is five hundred hours. About three months of work." Never three short lines or two long ones in a row.
- **One breath per line**, about 10 words, the way they'd say it to a mate. Contractions, "so", "and", "but".
- **Something new every 5-7 seconds.** A first useful thing by about 15 seconds. A big re-hook at the halfway point that opens a loop ("but number four's the one that costs the most"), closed later.
- **Lists:** say the count in the hook. Then "step one, step two" for a how-to, "number one, number two" for a list. Never "part one".
- **Payoff:** answer the question the hook asked. Then a last line that loops back into the first frame.
- **Length follows the value:** 25-35 seconds for one idea or a list of mistakes, 45-60 seconds for a how-to, longer only if every line earns it.

## Call to action

Two versions, A and B, so the video can be reposted. A keyword close works best: tease what they get, then "Comment [WORD], and I'll send you [the thing]." One CTA per video.

## Before you hand it over

Read it aloud in your head, start to finish, on every hook path. Fix any line a busy viewer wouldn't follow first time, any "it" that points at something not said yet, and anything not true.
